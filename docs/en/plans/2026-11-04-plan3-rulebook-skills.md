# Plan 3 — rulebook, skills and agent tooling

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let any teammate, human or AI tool, build warehouse data the Kimball/OneData way from the repository
alone. This plan adds:

- the rulebook in `docs/standards/` (13 files), cross-checked against the lint codes;
- eight process skills in `skills/`, tested with headless agent runs;
- `AGENTS.md` plus per-tool files generated by `dwh sync-agents`;
- `dwh scaffold`, which turns a design into model files;
- sqlfluff and pre-commit.

**Architecture:**
- **Sources of truth.** Only `skills/`, `docs/standards/`, `warehouse/` and `AGENTS.md` are hand-written; every
  per-tool file is generated from them and checked for drift in CI.
- **Rulebook format.** Each file is a list of numbered rules (`STD-NN-MM`) with a level, a correct and an incorrect
  example, a source, and the lint codes that check it. `dwh check-standards` (DWH-R) enforces that format and that
  every lint code is cited.
- **Skill testing.** Skills are written test-first: a scenario is run headless with `claude -p` on the base commit
  (RED, no skills) and on the new commit (GREEN).

**Tech Stack:** Python 3.12 and uv. The `dwh` package uses pyyaml 6.0.3, jsonschema 4.26.0 and pytest 9.2.0. Tools:
sqlfluff 4.5.0 (Trino dialect, jinja templater), pre-commit 4.7.0, Claude Code CLI 2.1.x (`claude -p`), dbt-core
1.11.16 and dbt-trino 1.11.0.

**Spec:** `docs/en/specs/2026-11-04-kimball-dwh-design.md`: §3, §6, §7, §7.1, §8 and §9 item 3. The Alibaba section
digest is `docs/en/research/2026-11-04-alibaba-dwh-digest.md`.

- Canonical sources: `AGENTS.md`, `skills/<name>/SKILL.md` (plus files beside it), `docs/standards/*.md` and
  `warehouse/*.yml`.
  - Generated (never hand-edited): `CLAUDE.md`, `GEMINI.md`, `.claude/skills/**`, `.cursor/rules/*.mdc` and
    `.github/copilot-instructions.md`.
  - Every generated file carries the line `Generated by \`dwh sync-agents\``.
- Skill format (agentskills.io, superpowers:writing-skills):
  - YAML frontmatter has only `name` and `description`, at most 1024 characters.
  - `name` equals the directory name: lowercase letters, digits and hyphens.
  - `description` starts with `Use when` and says only when to use the skill, never what it does.
  - A skill is at most about 2 pages. It holds process only and links to `docs/standards/` for rules.
- Rulebook format, one rule per section:

  ```text
  ### STD-NN-MM <title> (MUST|SHOULD)
  ```

  - NN is the file number.
  - The section needs a statement, a `Correct:` and an `Incorrect:` fenced example, and a `Source:` line.
  - The `Source:` parts are joined by ` · ` and each starts with `Kimball`, `Alibaba <slug>` or `Spec §`. A slug must
    be one of the digest's page slugs.
  - The section may have a `Checked by:` line that lists DWH codes.
- Kimball-only rules cite Kimball, never Alibaba (spec §7). Where the spec and Alibaba differ, the spec wins and the
  file says so.
- `dt` is the Asia/Ho_Chi_Minh business day (spec D12). Never `{{ ds }}`.
- Lint codes follow `DWH-<family><two digits>`.
  - Families: `Y N L M B T D S G` from plan 2, plus `R` (rulebook checks) from this plan.
  - Each finding prints one line: `<path>: <code> <message>`.
  - Exit codes: 0 when clean, 1 when there are findings, 2 when the input is unusable.
- ruff 0.17 formats Python code blocks inside Markdown. Every `.md` with a Python block must pass `make lint`:
  run `make fmt` and commit the result. Line length is 110 and E501 is on; split long strings by implicit
  concatenation.
- Code, comments, docs and commit messages are in English. Commits follow Conventional Commits and end with:

  ```text
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  ```

- The shell on the dev machine aliases `rm` and `cp` to interactive mode. Never use them; use git, `command cp -f`
  or Python `shutil`.
- Headless skill runs (`evals/run.sh`) call `claude -p` with read-only tools (`Read,Glob,Grep`) and
  `--setting-sources project`, so user plugins and memories do not leak into a run.

Measured before writing this plan (2026-11-04):

- **sqlfluff.** sqlfluff 4.5.0 lints both ODS models on the host with no Trino connection when it runs with:
  - `templater = jinja`;
  - `apply_dbt_builtins = True`;
  - `load_macros_from_path = dags/dbt/macros,dev/sqlfluff/macros`.

  The second macro path holds a stub `get_dt` macro, because dbt's `modules` does not exist under the jinja
  templater. With alias alignment (`[sqlfluff:layout:type:alias_expression] spacing_before = align`), the current
  models report no violations.
- **Snapshot from the current DIM.** dbt 1.11.16 parses a YAML snapshot with:
  - `relation: ref('dim_pub_customer')`;
  - `unique_key: [customer_key]`;
  - `strategy: check`, `check_cols: [city]`;
  - `snapshot_meta_column_names: {dbt_valid_from: valid_from, dbt_valid_to: valid_to}`.

  The manifest records the snapshot as depending on `model.example_dwh.dim_pub_customer`.
- **Headless runs.** `printf '<prompt>' | claude -p --setting-sources project --model <m> --allowedTools "Read,Glob,Grep"`
  answers from the repo's files and loads no user plugins.
  - `--allowedTools` is variadic, so the prompt must come on stdin.
  - `--bare` is unusable here because it needs an API key.

Decision taken in this plan (written into the spec in Task 13):
- The SCD4 `_hist` table is a dbt snapshot of the **current DIM model** (`dim_*`), keyed by the durable key. That way
  the history is deduplicated and keyed exactly as facts join it.
- DWH-L04 therefore lets a snapshot read DIM as well as ODS.
- `is_current` is not stored; consumers derive it as `valid_to is null`.

"""Every code the rules can emit is registered, and every registered code is emitted somewhere."""

import re
from pathlib import Path

from dwh.codes import CODES

SRC = Path(__file__).resolve().parents[1] / "src" / "dwh"
CODE = re.compile(r"\"(DWH-[A-Z]\d\d)\"")


def emitted_codes() -> set[str]:
    found = set()
    for path in SRC.rglob("*.py"):
        if path.name != "codes.py":
            found.update(CODE.findall(path.read_text()))
    return found


def test_every_emitted_code_is_registered():
    assert emitted_codes() - set(CODES) == set()


def test_every_registered_code_is_emitted():
    assert set(CODES) - emitted_codes() == set()


def test_meanings_are_one_line():
    assert all(meaning and "\n" not in meaning for meaning in CODES.values())
```

- [ ] **Step 3: Implement `standards.py`**

```python
"""`dwh check-standards`: the rulebook format (spec §7) and its link to the lint codes (DWH-R)."""

import re
from collections.abc import Iterator
from dataclasses import dataclass
from pathlib import Path

from dwh.codes import CODES
from dwh.findings import Finding, rel

STANDARD_FILES = (
    "00-principles.md",
    "01-layers.md",
    "02-naming.md",
    "03-domains-bus-matrix.md",
    "04-dimensions.md",
    "05-facts.md",
    "06-metrics.md",
    "07-dws-ads.md",
    "08-iceberg-incremental.md",
    "09-dbt-conventions.md",
    "10-trino-sql-style.md",
    "11-airflow.md",
    "12-data-quality.md",
)
# Pages with body text in the Alibaba "Build and optimize a data warehouse" section (research digest).
ALIBABA_SLUGS = frozenset(
    {
        "overall-process",
        "determine-business-requirements",
        "analyze-business-processes",
        "divide-data-domains",
        "define-dimensions-and-build-a-bus-matrix",
        "specify-statistical-metrics",
        "select-a-technical-architecture",
        "divide-a-data-warehouse-into-layers",
        "specify-the-principles-for-using-data-at-different-layers",
        "dim-layer",
        "data-warehouse-detail-layer",
        "data-warehouse-service-layer",
        "project-allocation-and-security",
        "performance-benchmark-establishment",
        "data-warehouse-performance-optimization",
        "result-verification",
    }
)
HEADING = re.compile(
    r"^### (?P<id>STD-(?P<file>\d\d)-(?P<n>\d\d)) (?P<title>\S.*) \((?P<level>MUST|SHOULD)\)$"
)
CODE = re.compile(r"\bDWH-[A-Z]\d\d\b")


@dataclass(frozen=True)
class Rule:
    id: str
    file_number: str
    lines: tuple[str, ...]


def split_rules(text: str) -> tuple[list[Rule], list[str]]:
    """Rules, plus the `### ` headings that are not valid rule headings. Headings inside fences are ignored."""
    rules: list[Rule] = []
    bad: list[str] = []
    current: tuple[str, str] | None = None
    body: list[str] = []
    in_fence = False

    def close() -> None:
        if current is not None:
            rules.append(Rule(current[0], current[1], tuple(body)))

    for line in text.splitlines():
        if line.startswith("```"):
            in_fence = not in_fence
        if not in_fence and (line.startswith("### ") or line.startswith("## ")):
            close()
            current, body = None, []
            if line.startswith("### "):
                match = HEADING.match(line)
                if match:
                    current = (match["id"], match["file"])
                else:
                    bad.append(line)
            continue
        if current is not None:
            body.append(line)
    close()
    return rules, bad


def has_example(lines: tuple[str, ...], label: str) -> bool:
    for i, line in enumerate(lines):
        if line.strip() == f"{label}:":
            following = [nxt for nxt in lines[i + 1 :] if nxt.strip()]
            return bool(following) and following[0].startswith("```")
    return False


def source_problem(lines: tuple[str, ...]) -> str | None:
    sources = [line for line in lines if line.startswith("Source: ")]
    if not sources:
        return "no Source: line"
    parts = [part.strip() for part in sources[0].removeprefix("Source: ").split("·")]
    for part in parts:
        if part.startswith("Alibaba"):
            slug = part.removeprefix("Alibaba").strip().split(" ")[0]
            if slug not in ALIBABA_SLUGS:
                return f"unknown Alibaba page {slug!r}"
    if not any(p.startswith(("Kimball", "Alibaba ", "Spec §")) for p in parts):
        return "Source: must cite Kimball, Alibaba <slug> or Spec §"
    return None


def cited_codes(lines: tuple[str, ...]) -> set[str]:
    checked = [line for line in lines if line.startswith("Checked by: ")]
    return set(CODE.findall(checked[0])) if checked else set()


def check_file(path: Path, seen: set[str]) -> Iterator[Finding | str]:
    """Findings for one file; also yields every cited code as a bare string."""
    where = rel(path)
    rules, bad = split_rules(path.read_text())
    for heading in bad:
        yield Finding(
            where, "DWH-R02", f"malformed rule heading {heading!r}: use '### STD-NN-MM <title> (MUST|SHOULD)'"
        )
    for rule in rules:
        if rule.file_number != path.name[:2]:
            yield Finding(
                where, "DWH-R02", f"{rule.id}: rule number must start with this file's number {path.name[:2]}"
            )
        if rule.id in seen:
            yield Finding(where, "DWH-R02", f"{rule.id}: duplicate rule id")
        seen.add(rule.id)
        for label in ("Correct", "Incorrect"):
            if not has_example(rule.lines, label):
                yield Finding(where, "DWH-R03", f"{rule.id}: no '{label}:' line followed by a fenced example")
        problem = source_problem(rule.lines)
        if problem:
            yield Finding(where, "DWH-R04", f"{rule.id}: {problem}")
        for code in sorted(cited_codes(rule.lines)):
            if code not in CODES:
                yield Finding(where, "DWH-R05", f"{rule.id}: unknown lint code {code}")
            else:
                yield code


def check_standards(root: Path, require_all: bool = False) -> list[Finding]:
    findings: list[Finding] = []
    cited: set[str] = set()
    seen: set[str] = set()
    for name in STANDARD_FILES:
        path = root / name
        if not path.is_file():
            if require_all:
                findings.append(Finding(rel(path), "DWH-R01", "required standards file is missing"))
            continue
        for item in check_file(path, seen):
            if isinstance(item, Finding):
                findings.append(item)
            else:
                cited.add(item)
    if require_all:
        for code in sorted(CODES):
            if not code.startswith("DWH-R") and code not in cited:
                findings.append(
                    Finding(rel(root), "DWH-R06", f"{code} ({CODES[code]}) is not cited by any rule")
                )
    return sorted(set(findings))
```

```python
"""`dwh sync-agents`: generate each AI tool's instruction files from AGENTS.md and skills/ (spec §3, D1)."""

import json
import re
from dataclasses import dataclass
from pathlib import Path

import yaml

MARKER = (
    "<!-- Generated by `dwh sync-agents` from {source}. "
    "Do not edit: change the source and run `make sync-agents`. -->"
)
FRONTMATTER = re.compile(r"\A---\n(?P<yaml>.*?)\n---\n(?P<body>.*)\Z", re.S)
SKILL_NAME = re.compile(r"^[a-z0-9]+(-[a-z0-9]+)*$")
GENERATED_DIRS = (".claude/skills", ".cursor/rules")


class SkillError(ValueError):
    """A skill or AGENTS.md cannot be turned into tool files."""


@dataclass(frozen=True)
class Skill:
    name: str
    description: str
    directory: Path
    body: str


def load_skill(directory: Path) -> Skill:
    path = directory / "SKILL.md"
    match = FRONTMATTER.match(path.read_text())
    if not match:
        raise SkillError(f"{path}: missing YAML frontmatter")
    meta = yaml.safe_load(match["yaml"]) or {}
    if set(meta) != {"name", "description"}:
        raise SkillError(f"{path}: frontmatter must have only name and description, got {sorted(meta)}")
    if len(match["yaml"]) > 1024:
        raise SkillError(f"{path}: frontmatter is longer than 1024 characters")
    name, description = meta["name"], meta["description"]
    if name != directory.name or not SKILL_NAME.match(str(name)):
        raise SkillError(f"{path}: name {name!r} must equal the directory name and use [a-z0-9-]")
    if not isinstance(description, str) or not description.startswith("Use when"):
        raise SkillError(f"{path}: description must start with 'Use when'")
    return Skill(name, description, directory, match["body"])


def load_skills(skills_dir: Path) -> list[Skill]:
    skills = []
    for directory in sorted(p for p in skills_dir.iterdir() if p.is_dir()) if skills_dir.is_dir() else []:
        if not (directory / "SKILL.md").is_file():
            raise SkillError(f"{directory}: no SKILL.md")
        skills.append(load_skill(directory))
    return skills


def with_marker_after_frontmatter(text: str, source: str) -> str:
    match = FRONTMATTER.match(text)
    assert match  # validated by load_skill
    return f"---\n{match['yaml']}\n---\n{MARKER.format(source=source)}\n{match['body']}"


def render(repo: Path) -> dict[str, str]:
    agents_path = repo / "AGENTS.md"
    if not agents_path.is_file():
        raise SkillError(f"{agents_path}: AGENTS.md is missing")
    agents = agents_path.read_text()
    skills = load_skills(repo / "skills")
    out: dict[str, str] = {}
    pointer = f"{MARKER.format(source='AGENTS.md')}\n@AGENTS.md\n"
    out["CLAUDE.md"] = pointer
    out["GEMINI.md"] = pointer
    for skill in skills:
        for path in sorted(p for p in skill.directory.rglob("*") if p.is_file()):
            relative = path.relative_to(repo / "skills").as_posix()
            text = path.read_text()
            if path.name == "SKILL.md" and path.parent == skill.directory:
                text = with_marker_after_frontmatter(text, f"skills/{relative}")
            out[f".claude/skills/{relative}"] = text
        out[f".cursor/rules/{skill.name}.mdc"] = (
            f"---\ndescription: {json.dumps(skill.description)}\nalwaysApply: false\n---\n"
            f"{MARKER.format(source=f'skills/{skill.name}/SKILL.md')}\n\n{skill.body.lstrip()}"
        )
    out[".cursor/rules/agents.mdc"] = (
        "---\ndescription: example-dwh rules for every data change\nalwaysApply: true\n---\n"
        f"{MARKER.format(source='AGENTS.md')}\n\n{agents}"
    )
    skill_lines = "".join(f"- `skills/{s.name}/SKILL.md`: {s.description}\n" for s in skills)
    out[".github/copilot-instructions.md"] = (
        f"{MARKER.format(source='AGENTS.md and skills/')}\n\n{agents.rstrip()}\n\n"
        f"## Skills\n\nOpen the matching skill file before doing that kind of work:\n\n{skill_lines}"
    )
    return out


def stale_files(repo: Path, expected: dict[str, str]) -> list[str]:
    stale = []
    for directory in GENERATED_DIRS:
        root = repo / directory
        if root.is_dir():
            for path in sorted(p for p in root.rglob("*") if p.is_file()):
                relative = path.relative_to(repo).as_posix()
                if relative not in expected:
                    stale.append(relative)
    return stale


def sync(repo: Path, check: bool) -> list[str]:
    """Write (or, with check, only compare) every generated file. Returns what changed or would change."""
    expected = render(repo)
    changed = []
    for relative, content in sorted(expected.items()):
        path = repo / relative
        if not path.is_file() or path.read_text() != content:
            changed.append(relative)
            if not check:
                path.parent.mkdir(parents=True, exist_ok=True)
                path.write_text(content)
    for relative in stale_files(repo, expected):
        changed.append(f"{relative} (stale)")
        if not check:
            (repo / relative).unlink()
    return changed
```

| dws | `.sql`, `.yml` | `--grain`, `--from`, `--metric` (derived, same period; 1d, nd, td or 1w) | contract; `meta.grain`; metric columns with `meta.metric` and an aggregation `filter (where <modifiers> and <period>)`; `relationships` on grain keys. |
| ads | `.sql`, `.yml` | `--grain`, `--from`, `--metric` (derived or calculated) | grain + dt tests; metric columns with `meta.metric`; a calculated metric is written as its formula. |

Data types follow the column suffix (02-naming):

| Suffix | Type |
|--------|------|
| `_key` | `varchar` |
| `_id`, `_cnt`, `_dcnt` | `bigint` |

| `_at` | `timestamp(6) with time zone` |
| `_date`, `dt` | `date` |

from pathlib import Path, PurePosixPath
from string import Template

import yaml

from dwh.rules.naming import PATTERNS
from dwh.warehouse import Warehouse

HEADER = "# Generated by `dwh scaffold`. Fill every description (DWH-D01/D02) and check each data_type.\n"
AGGREGATE = {"sum": "sum({measure})", "count": "count(*)", "min": "min({measure})", "max": "max({measure})"}
TODAY = "date '{{ get_dt() }}'"
PARTITION_CONFIG = """{{
  config(
    incremental_strategy='append',
    pre_hook="{% if is_incremental() %}delete from {{ this }} where dt = date '{{ get_dt() }}'{% endif %}",
    properties={"partitioning": "ARRAY['dt']"}
  )
}}
"""

ODS_SQL = Template(
    """{#
  $comment
  Replace the dt partition: delete it first, then append the batch, so re-runs are idempotent.
#}
$config
{% set tz = source_timezone('$source', '$table') %}

select
    -- List and cast every source column; convert timestamps with source_ts('<column>', tz).
$columns    date '{{ get_dt() }}' as dt
from {{ source('$source', '$table') }}
$where"""
)
DIM_SQL = Template(

-- One current row per natural key (spec D11); the durable key is a hash of the natural key.
select
    {{ dbt_utils.generate_surrogate_key([$natural]) }} as $key,
$columns

-- For a df upstream keep its latest snapshot; adapt the filter for a di upstream.
where dt = (select max(dt) from {{ ref('$upstream') }})
"""
)
DWD_SQL = Template(

$joins\

"""
)

)
ADS_SQL = Template(

class ScaffoldError(ValueError):
    """The requested model cannot be scaffolded from the current design."""


def data_type(column: str) -> str:
    if column == "dt" or column.endswith("_date"):
        return "date"
    if column.endswith("_key"):
        return "varchar"
    if column.endswith(("_id", "_cnt", "_dcnt")):
        return "bigint"
    if column.endswith("_amt"):
        return "decimal(18, 2)"
    if column.endswith("_at"):
        return "timestamp(6) with time zone"
    if column.startswith("is_"):
        return "boolean"
    return "varchar"


def metric_type(wh: Warehouse, metric: str) -> str:
    if metric in wh.calculated:
        return "double"
    aggregation = wh.atomic[wh.derived[metric]["atomic"]]["aggregation"]
    return "bigint" if aggregation in ("count", "count_distinct") else "decimal(38, 4)"


def column(name: str, *, contract: bool, tests=(), meta=None, dtype: str | None = None) -> dict:
    col: dict = {"name": name, "description": ""}
    if contract:
        col["data_type"] = dtype or data_type(name)
    if meta:
        col["config"] = {"meta": meta}
    if tests:
        col["data_tests"] = list(tests)
    return col


def relationships(model: str, field: str) -> dict:
    return {"relationships": {"arguments": {"to": f"ref('{model}')", "field": field}}}


def models_yml(name: str, columns: list[dict], *, grain: list[str] | None, contract=False, meta=None) -> str:
    model: dict = {"name": name, "description": ""}
    config: dict = {}
    if contract:
        config["contract"] = {"enforced": True}
    if meta:
        config["meta"] = meta
    if config:
        model["config"] = config
    model["columns"] = columns
    if grain is not None:
        model["data_tests"] = [
            {"dbt_utils.unique_combination_of_columns": {"arguments": {"combination_of_columns": grain}}}
        ]
    return HEADER + yaml.safe_dump({"version": 2, "models": [model]}, sort_keys=False, width=110)


def dim_model(dimension: dict) -> str:
    return f"dim_{dimension['scope']}_{dimension['name']}"


def key_dimensions(wh: Warehouse) -> dict[str, dict]:
    """`<name>` of a `<name>_key` column -> its dimension: dimension names and bus-matrix role names."""
    found = dict(wh.dimensions)
    for row in wh.bus.values():
        for cell in row["dimensions"]:
            if "role" in cell:
                found[cell["role"]] = wh.dimensions[cell["dimension"]]
    return found


def surrogate(dimension: dict) -> str:
    natural = ", ".join(f"'{k}'" for k in dimension["natural_key"])
    return f"{{{{ dbt_utils.generate_surrogate_key([{natural}]) }}}}"


def _ods(name, parts, wh, grain, metrics, upstream, watermark) -> dict[str, str]:
    source, table, load = parts["source"], parts["table"], parts["load"]
    comment = (
        f"Daily increment of {source}.{table} for the business day dt (spec D12)."
        if load == "di"
        else f"Daily full copy of {source}.{table} into the business day dt (spec D12)."
    )
    sql = ODS_SQL.substitute(
        comment=comment,
        config=PARTITION_CONFIG,
        source=source,
        table=table,
        columns="".join(f"    {g},\n" for g in grain),
        where=f"where {{{{ in_business_day('{watermark}', tz) }}}}\n" if load == "di" else "",
    )
    columns = [column(g, contract=False, tests=["not_null"]) for g in grain]
    columns.append(column("dt", contract=False, tests=["not_null"]))
    folder = f"models/ods/{source}"
    return {
        f"{folder}/{name}.sql": sql,
        f"{folder}/{name}.yml": models_yml(name, columns, grain=[*grain, "dt"]),
    }


def _dim(name, parts, wh, grain, metrics, upstream, watermark) -> dict[str, str]:
    scope, dim_name = parts["scope"], parts["dimension"]
    if parts["hist"]:
        raise ScaffoldError(f"{name}: _hist tables are snapshots; scaffold dim_{scope}_{dim_name} to get one")
    dimension = wh.dimensions.get(dim_name)
    if dimension is None:
        raise ScaffoldError(f"{name}: dimension {dim_name!r} is not in warehouse/dimensions.yml")
    if dimension["scope"] != scope:
        raise ScaffoldError(
            f"{name}: dimension {dim_name} has scope {dimension['scope']}, so the model is {dim_model(dimension)}"
        )
    if dimension["history"] == "scd2":
        raise ScaffoldError(f"{name}: scd2 is a documented exception (spec D11); write it by hand")
    if len(upstream) != 1:
        raise ScaffoldError(f"{name}: --from takes exactly one upstream model for a dimension")
    key = f"{dim_name}_key"
    natural = dimension["natural_key"]
    attributes = [a["name"] for a in dimension["attributes"]]
    sql = DIM_SQL.substitute(
        natural=", ".join(f"'{k}'" for k in natural),
        key=key,
        columns=",\n".join(f"    {c}" for c in [*natural, *attributes]),
        upstream=upstream[0],
    )
    columns = [column(key, contract=True, tests=["unique", "not_null"])]
    columns += [column(k, contract=True, tests=["not_null"]) for k in natural]
    columns += [column(a, contract=True) for a in attributes]
    folder = f"models/dim/{scope}"
    files = {
        f"{folder}/{name}.sql": sql,
        f"{folder}/{name}.yml": models_yml(name, columns, grain=None, contract=True),
    }
    if dimension["history"] == "scd4":
        historical = [a["name"] for a in dimension["attributes"] if a["history"] == "historical"]
        if not attributes:
            raise ScaffoldError(f"{name}: an scd4 dimension needs at least one attribute to track")
        snapshot = {
            "snapshots": [
                {
                    "name": f"{name}_hist",
                    "relation": f"ref('{name}')",
                    "description": "",
                    "config": {
                        "unique_key": [key],
                        "strategy": "check",
                        "check_cols": historical or attributes,
                        "snapshot_meta_column_names": {
                            "dbt_valid_from": "valid_from",
                            "dbt_valid_to": "valid_to",
                        },
                    },
                }
            ]
        }
        files[f"snapshots/{name}_hist.yml"] = HEADER + yaml.safe_dump(snapshot, sort_keys=False, width=110)
    return files


def _dwd(name, parts, wh, grain, metrics, upstream, watermark) -> dict[str, str]:
    domain, process_name = parts["domain"], parts["process"]
    process = wh.processes.get(process_name)
    if process is None:
        raise ScaffoldError(f"{name}: process {process_name!r} is not in warehouse/processes.yml")
    if process["domain"] != domain:
        raise ScaffoldError(f"{name}: process {process_name} belongs to domain {process['domain']}")
    row = wh.bus.get(process_name)
    if row is None:
        raise ScaffoldError(f"{name}: add a warehouse/bus_matrix.yml row for process {process_name} first")
    keys = {
        f"{cell.get('role', cell['dimension'])}_key": wh.dimensions[cell["dimension"]]
        for cell in row["dimensions"]
    }
    select = [f"    {g}" for g in grain if g not in keys]
    select += [f"    {surrogate(dimension)} as {key}" for key, dimension in keys.items()]
    sql = DWD_SQL.substitute(
        config=PARTITION_CONFIG,
        process=process_name,
        grain_sentence=process["grain"],
        joins="".join(f"-- joins {{{{ ref('{model}') }}}}\n" for model in upstream[1:]),
        columns=",\n".join(select),
        upstream=upstream[0],
    )
    columns = []
    for g in grain:
        tests = ["not_null"]
        if g in keys:
            tests.append(relationships(dim_model(keys[g]), f"{keys[g]['name']}_key"))
        columns.append(column(g, contract=True, tests=tests))
    for key, dimension in keys.items():
        if key not in grain:
            columns.append(
                column(
                    key,
                    contract=True,
                    tests=[relationships(dim_model(dimension), f"{dimension['name']}_key")],
                )
            )
    columns.append(column("dt", contract=True, tests=["not_null"]))
    folder = f"models/dwd/{domain}"
    return {
        f"{folder}/{name}.sql": sql,
        f"{folder}/{name}.yml": models_yml(
            name, columns, grain=[*grain, "dt"], contract=True, meta={"process": process_name}
        ),
    }


def period_condition(derived: dict, period: str) -> str | None:
    if period == "1d":
        return f"dt = {TODAY}"
    if period == "1w":
        return f"dt > {TODAY} - interval '7' day"
    if period == "nd":
        return f"dt > {TODAY} - interval '{derived['days']}' day"
    return None  # td: all history up to dt


def _dws(name, parts, wh, grain, metrics, upstream, watermark) -> dict[str, str]:
    domain, period = parts["domain"], parts["period"]
    if domain not in wh.domains:
        raise ScaffoldError(f"{name}: {domain!r} is not a domain in warehouse/domains.yml")
    if period in ("hh", "mm"):
        raise ScaffoldError(f"{name}: scaffold supports 1d, nd, td and 1w DWS tables")
    if not metrics:
        raise ScaffoldError(f"{name}: --metric is required for a DWS table")
    dims = key_dimensions(wh)
    select = [f"    {g}" for g in grain]
    metric_columns = []
    for metric in metrics:
        derived = wh.derived.get(metric)
        if derived is None:
            raise ScaffoldError(f"{metric}: is not a derived metric in warehouse/metrics.yml")
        if derived["period"] != period:
            raise ScaffoldError(
                f"{metric}: period {derived['period']} does not match the table period {period}"
            )
        atomic = wh.atomic[derived["atomic"]]
        if atomic["aggregation"] not in AGGREGATE:
            raise ScaffoldError(f"{metric}: {atomic['aggregation']} metrics are not stored in DWS (DWH-M02)")
        expression = AGGREGATE[atomic["aggregation"]].format(measure=atomic["name"])
        conditions = [wh.modifiers[m]["predicate"] for m in derived.get("modifiers", [])]
        window = period_condition(derived, period)
        if window:
            conditions.append(window)
        if conditions:
            expression += f" filter (where {' and '.join(conditions)})"
        select.append(f"    {expression} as {metric}")
        metric_columns.append(
            column(metric, contract=True, meta={"metric": metric}, dtype=metric_type(wh, metric))
        )
    sql = DWS_SQL.substitute(
        config=PARTITION_CONFIG,
        period=period,
        columns=",\n".join(select),
        upstream=upstream[0],
        group_by=", ".join(grain),
    )
    columns = []
    for g in grain:
        tests: list = ["not_null"]
        stem = g.removesuffix("_key")
        if g.endswith("_key"):
            if stem not in dims:
                raise ScaffoldError(f"{name}: grain key {g} does not name a dimension or bus-matrix role")
            tests.append(relationships(dim_model(dims[stem]), f"{dims[stem]['name']}_key"))
        columns.append(column(g, contract=True, tests=tests))
    columns += metric_columns
    columns.append(column("dt", contract=True, tests=["not_null"]))
    folder = f"models/dws/{domain}"
    return {
        f"{folder}/{name}.sql": sql,
        f"{folder}/{name}.yml": models_yml(
            name, columns, grain=[*grain, "dt"], contract=True, meta={"grain": grain}
        ),
    }


def _ads(name, parts, wh, grain, metrics, upstream, watermark) -> dict[str, str]:
    if not metrics:
        raise ScaffoldError(f"{name}: --metric is required for an ADS table")
    select = [f"    {g}" for g in grain]
    for metric in metrics:
        if metric in wh.derived:
            select.append(f"    {metric}")
        elif metric in wh.calculated:
            select.append(f"    {wh.calculated[metric]['formula']} as {metric}")
        else:
            raise ScaffoldError(f"{metric}: is not a derived or calculated metric in warehouse/metrics.yml")
    sql = ADS_SQL.substitute(columns=",\n".join(select), upstream=upstream[0])
    columns = [column(g, contract=False, tests=["not_null"]) for g in grain]
    columns += [column(m, contract=False, meta={"metric": m}) for m in metrics]
    columns.append(column("dt", contract=False, tests=["not_null"]))
    folder = f"models/ads/{parts['app']}"
    return {
        f"{folder}/{name}.sql": sql,
        f"{folder}/{name}.yml": models_yml(name, columns, grain=[*grain, "dt"]),
    }


BUILDERS = {"ods": _ods, "dim": _dim, "dwd": _dwd, "dws": _dws, "ads": _ads}


def scaffold(
    name: str,
    wh: Warehouse,
    *,
    project_dir: str = "dags/dbt",
    grain=(),
    metrics=(),
    upstream=(),
    watermark: str = "updated_at",
) -> dict[str, str]:
    layer = name.split("_", 1)[0]
    pattern = PATTERNS.get(layer)
    if pattern is None:
        raise ScaffoldError(f"{name}: the name must start with ods_, dim_, dwd_, dws_ or ads_")
    match = pattern.match(name)
    if match is None:
        raise ScaffoldError(
            f"{name}: does not follow the {layer} naming template (docs/standards/02-naming.md)"
        )
    if layer != "dim" and not grain:
        raise ScaffoldError(f"{name}: --grain is required (the columns that, with dt, identify one row)")
    if layer != "ods" and not upstream:
        raise ScaffoldError(f"{name}: --from is required (the upstream model or models)")
    files = BUILDERS[layer](
        name, match.groupdict(), wh, list(grain), list(metrics), list(upstream), watermark
    )
    return {
        (str(PurePosixPath(project_dir, path)) if project_dir else path): text for path, text in files.items()
    }


def write_files(files: dict[str, str], repo: Path) -> list[str]:
    existing = [path for path in files if (repo / path).exists()]
    if existing:
        raise ScaffoldError(f"refusing to overwrite {', '.join(existing)}")
    for path, text in files.items():
        target = repo / path
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_text(text)
    return list(files)
```

```bash
#!/usr/bin/env bash
# Run one skill scenario headless with Claude Code (spec §8.2) and save the answer for grading.
#   evals/run.sh <scenario> [--ref <git-ref>] [--model <model>]
# --ref defaults to HEAD; use the plan's base commit for a RED (no-skills) baseline.
# The run sees the repository at <ref>, plus the scenario's fixture copied over it, with read-only tools.
set -euo pipefail
REPO="$(cd "$(dirname "$0")/.." && pwd)"
NAME=${1:?usage: evals/run.sh <scenario> [--ref <git-ref>] [--model <model>]}
shift
REF=HEAD
MODEL=sonnet
while [ $# -gt 0 ]; do
  case $1 in
    --ref) REF=$2; shift 2 ;;
    --model) MODEL=$2; shift 2 ;;
    *) echo "unknown argument: $1" >&2; exit 2 ;;
  esac
done
SCENARIO="$REPO/evals/scenarios/$NAME.md"
[ -f "$SCENARIO" ] || { echo "no scenario $SCENARIO" >&2; exit 2; }

WORK="$(mktemp -d "${TMPDIR:-/tmp}/dwh-eval.XXXXXX")"
git -C "$REPO" worktree add --detach --quiet "$WORK/repo" "$REF"
trap 'git -C "$REPO" worktree remove --force "$WORK/repo"' EXIT

FIXTURE=$(sed -n 's/^fixture: *//p' "$SCENARIO" | head -1)
if [ -n "$FIXTURE" ]; then
  python3 -c 'import shutil, sys; shutil.copytree(sys.argv[1], sys.argv[2], dirs_exist_ok=True)' \
    "$REPO/evals/fixtures/$FIXTURE" "$WORK/repo"
fi
PROMPT=$(sed -n '/^## Prompt/,/^## /{/^## /d;p;}' "$SCENARIO")

mkdir -p "$REPO/evals/results"
OUT="$REPO/evals/results/$NAME-$(git -C "$REPO" rev-parse --short "$REF")-$MODEL.md"
(cd "$WORK/repo" && printf '%s\n' "$PROMPT" \
  | claude -p --setting-sources project --model "$MODEL" --allowedTools "Read,Glob,Grep") > "$OUT"
echo "wrote $OUT"
```

# dwh-start: classify the change first

Every data change starts here. Classify it, say the class, then follow its path. No SQL before this.

## Steps

| Class | Signals | Path |
|-------|---------|------|
| Model-extending | new domain, business process, conformed dimension or atomic metric; a grain change; a new source system | dwh-requirement → dwh-model-design → **stop for human approval** → dwh-implement → dwh-verify → PR |
| Reuse | derived metric from an existing atomic metric; new ADS table; new attribute on an existing dimension; logic or bug fix | table spec in the PR description → dwh-implement → dwh-verify → PR |

| "It's urgent, skip the process" | Classifying takes two minutes; a wrong grain or a duplicate metric costs days. Classify, then move fast on the right path. |

# dwh-verify: evidence before claims

No command output, no claim. "Looks right" and "should work" are not evidence.

## Steps

1. **Build** on dev for the dt you changed:

   ```bash
   docker compose -f dev/compose.yml run --rm airflow \
     'cd dags/dbt && $DBT_EXECUTABLE_PATH build --select <model>+ --vars "{dt: YYYY-MM-DD}"'
   ```

2. **Lint.** `make dwh-lint`, `make sql-lint` and `make lint` must each report 0 findings.

4. **Idempotency.** Build the same dt twice; the counts must not change.
5. **Performance baseline.** Record wall time, input rows and bytes, output rows, and Iceberg file count and size
   for the dt. For a change to an existing model, record the same numbers before and after.
6. **Paste the evidence.** Put the commands and their real output in the PR description. If anything failed, say
   so; do not round it away.

## Red flags

| Thought | Reality |
|---------|---------|
| "The SQL is simple, it obviously works" | Simple SQL still fans out on a bad join. Run the counts. |
| "Tests passed earlier" | Earlier is not this code or this dt. Run them again. |
| "I'll add the evidence after review" | Reviewers cannot check a claim without its output. |
| "I verified a different dt" | Verify the dt you changed, plus the next one. |

## Rules

`docs/standards/12-data-quality.md`, `08-iceberg-incremental.md`.

name: dwh-debug
description: Use when a dbt build, Airflow task or Trino query fails, or when a warehouse number does not match its source or another report

# dwh-debug: root cause before fix

## Steps

1. **Reproduce.** Write down the exact dt, model, command and error, or the two numbers that disagree. Re-run once
   to rule out a transient failure (Trino node loss, S3 throttling).
2. **Locate the layer.** Trace lineage downward, ADS → DWS → DWD → DIM/ODS → source (`dbt ls --select +<model>`).
   At each hop, compare row count and one amount for the same dt. The first hop that disagrees is where the defect
   is.
3. **Classify the cause:**

   | Area | Typical causes |
   |------|----------------|
   | Source | late rows; deletes a di watermark cannot see; timezone |
   | Load | Vietnam-day window against the source timezone; watermark; delete handling |
   | Model | join fan-out; point-in-time SCD join; filters |
   | Metric | modifier or period definition |
   | Orchestration | dt wiring (`DT_TEMPLATE`); Asset triggers |
4. **Capture it in a test.** Write a failing test (dbt unit test or data test) that captures the cause, before
   fixing.
5. **Fix at the lowest wrong layer.** Then rebuild every downstream model for the affected dts (`dwh-backfill`).
6. **Record** the cause, the failing test and the evidence in the PR.

## Red flags

| Thought | Reality |
|---------|---------|
| "Patch the dashboard/ADS to match" | The wrong number stays in DWD and spreads to every other consumer. |
| "Retry until it's green" | A deterministic error fails again tomorrow. Find it. |
| "Change the test's expected value" | The test was the evidence. Change it only when the expectation was wrong, and say why. |
| "Fix quickly, investigate later" | A fix without a located cause is a guess. |

## Rules

`docs/standards/08-iceberg-incremental.md`, `12-data-quality.md`, `11-airflow.md`.

name: dwh-backfill
description: Use when past dt partitions must be rebuilt - after a logic fix, late-arriving data, a source correction, or a new model that needs history
---

# dwh-backfill: safe partition re-runs

## Steps

1. **Scope.** List the affected models (`dbt ls --select <model>+`) and the dt range. Estimate rows and Trino cost
   from the performance baseline.
2. **Dry run.** Build one dt on dev and compare its counts with prod.
3. **Run in order.** Start with the oldest dt and run one dt at a time (`dbt build --vars "{dt: ...}"` in a loop, or
   `airflow dags backfill`). Each run replaces its own partition, so re-running a dt is safe.
4. **Rebuild windowed DWS to today.** `nd` and `td` DWS tables must be rebuilt for every dt from the earliest
   changed dt to today, because a `td` value depends on every earlier day.
5. **Leave history alone.** Re-running snapshots does not rebuild `dim_*_hist`. Rebuild history only with an
   approved, written plan.
6. **Verify each dt** (`dwh-verify` steps 3–4) and record the range and the evidence in the PR.

## Red flags

| Thought | Reality |
|---------|---------|
| "Run all 30 dts in parallel to save time" | Parallel writes to one Iceberg table conflict and retry. Run one dt at a time. |
| "Reload ODS for past dates" | A df source only has today's state: past ODS partitions cannot be recreated from it. |
| "Only the fixed model needs rebuilding" | Every downstream model, including DWS `nd`/`td` up to today. |

## Rules

`docs/standards/08-iceberg-incremental.md`, `12-data-quality.md`.
